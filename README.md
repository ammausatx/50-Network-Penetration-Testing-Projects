# 50 Network Penetration Testing Projects

A practical, progressive portfolio of 50 network security assessment projects covering reconnaissance, host and service discovery, infrastructure review, segmentation, enterprise assessment, detection validation, and reporting.

> **Authorization and safety:** Perform active testing only against systems you own or have explicit written permission to assess. Use isolated lab networks for intrusive validation. Do not scan public IP ranges, third-party infrastructure, or production systems without documented authorization and an approved rules-of-engagement document. All screenshots in this repository are simulated training illustrations, not evidence from a real engagement.

## Standard project deliverables

Each project includes objectives, authorization and scope, prerequisites, a lab design, tools, a repeatable workflow, safe example commands, expected observations, risk interpretation, remediation guidance, validation steps, evidence guidance, and three clearly labeled simulated training illustrations.

## Suggested lab toolkit

- **Discovery and mapping:** Nmap, arp-scan, iproute2, traceroute, Wireshark
- **Service and protocol review:** OpenSSL, curl, dig, nslookup, snmpwalk, smbclient
- **Vulnerability assessment:** Greenbone/OpenVAS and authenticated configuration review
- **Analysis and reporting:** Python, CSV/JSON, draw.io or equivalent diagramming tools

Use intentionally vulnerable targets only in an isolated virtual network. Keep host-only or internal lab interfaces separate from your home, work, and public networks.
